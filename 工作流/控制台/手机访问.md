# 控制台手机访问（P0-2）

控制台是本机 HTTP 服务，手机访问有三条路，按推荐度排序：

## 方案 A（最推荐）：直接在 Muse 里对话驱动 ✅ 已可用

你在 Android 的 Muse App 里跟我说一句话需求（比如"做一份双11战报 PPT"），
我直接跑完整流水线（一句话→填写单→组装→校验→生图→HTML/PNG→PPTX），
成品文件发你。不用开电脑、不用配网络。

## 方案 B：同 WiFi 局域网访问

1. 在电脑上启动控制台并监听局域网：
   ```
   python 工作流/控制台/server.py --host 0.0.0.0 --port 8901
   ```
   启动后会打印局域网地址，如 `http://192.168.1.5:8901/`。
2. 手机连**同一个 WiFi**，浏览器打开那个地址。
3. 页面已做移动端适配（单列主题卡、响应式表单）。

注意：`--host 0.0.0.0` 会把控制台暴露给整个局域网，**只在可信网络使用**；
公司/公共 WiFi 不要用。控制台没有登录鉴权，任何人打开都能操作。

## 方案 C：公网访问（进阶）

把控制台跑在有公网 IP 的云服务器上，前面加反向代理（nginx/caddy）并配
HTTPS + 密码鉴权（basic auth）。不建议直接把 `--host 0.0.0.0` 暴露到公网。

---

## 排查

- 手机打不开地址：先确认手机和电脑连的是**同一个** WiFi；电脑防火墙放行 8901 端口。
- 页面显示不全：控制台页面已适配手机竖屏，横屏/平板体验更好。
- 导出 PPTX 在手机上：点"导出 PPTX"会直接下载 .pptx 文件，用 WPS/Office 打开。
