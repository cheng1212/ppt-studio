# 页型卡-compare_vs

- id: 页型卡-compare_vs
- 卡型: 页型卡
- 标题: 镜像双栏 VS
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案
- 版式族: 对比

## 适用场景

二选一式对比：两个选项在同一组维度上逐条对位比较，如"A 方案 vs B 方案""自研 vs 外采"。
左右镜像两栏，中央 VS＋竖分隔线；要点逐条平行对位；结论倾向放底部 verdict 条。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `compare_vs`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| a_title | 是 | 左侧选项名 |
| b_title | 是 | 右侧选项名 |
| a_points | 是 | 数组，2–5 项字符串：a 侧要点 |
| b_points | 是 | 数组，2–5 项字符串：b 侧要点 |
| verdict | 否 | 结论倾向（沉底通栏，如推荐哪一侧＋一句话理由） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 两侧条目必须对位回答同一问题；信息量对称（条数/长度量级一致）。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_compare_vs`；PPTX 声明式映射见 程序/pptx映射.py `映射表["compare_vs"]`
