# 页型卡-scr_brief

- id: 页型卡-scr_brief
- 卡型: 页型卡
- 标题: SCR 一页纸
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

一页讲清背景—冲突—结论：S/C/R 三段纵向排布（S/C/R 标签＋正文），
R 段视觉强调。适合汇报摘要页、一页纸备忘录、邮件式简报页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `scr_brief`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（结论句） |
| s | 是 | Situation：背景，2–3 行 |
| c | 是 | Complication：冲突/变化，2–3 行 |
| r | 是 | Resolution：结论与建议，2–3 行（强调） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 只写 Situation 不写 Complication 的无张力摘要禁入：s、c、r 三段缺一不可（校验闸拦截）。
- 每段 2–3 行，不许写成段落；r 必须是行动导向的结论与建议，不许只复述背景。
- 配色走主题令牌，不许在字段里写色值。

程序/页面生成.py `t_scr_brief`；PPTX 声明式映射见 程序/pptx映射.py `映射表["scr_brief"]`
