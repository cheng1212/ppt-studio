# 页型卡-scorecard_status

- id: 页型卡-scorecard_status
- 卡型: 页型卡
- 标题: 状态记分卡
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

项目状态汇报页：行列表（条目＋状态徽色块＋进度条），legend 为阈值图例行。
适合周报、阶段评审、项目组合状态页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `scorecard_status`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题 |
| items | 是 | 数组，3–7 项；每项：k（条目，必填）/ status（状态文本，必填）/ prog（进度 0–100 数字，选填） |
| legend | 否 | 阈值图例（如"≥80 正常 / 50–80 关注 / <50 告警"） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- status 必须用闭集化措辞（如正常/关注/告警/阻塞），全页口径统一，不许自由发挥。
- prog 必须是 0–100 数字（校验闸拦截）；状态徽颜色走主题状态令牌，不许自定义。
- items 必须为 3–7 项（校验闸拦截）。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_scorecard_status`；PPTX 声明式映射见 程序/pptx映射.py `映射表["scorecard_status"]`
