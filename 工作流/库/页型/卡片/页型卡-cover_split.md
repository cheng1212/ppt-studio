- id: 页型卡-cover_split
- 卡型: 页型卡
- 标题: 封面（左右分栏：左文右图）
- 来源轨: 专家报告 encoding（Topic 5.1 图文布局 60/40）
- 生产者: chengge
- 状态: 定稿
- 版式族: 封面

## 适用场景

封面变体：左 60% 文字定调，右 40% 竖构图。与 `cover`（满版图压字）的区别：
`cover` 适合氛围感大场景；`cover_split` 适合人物/产品特写图，文字区干净无压字。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 P1-封面），HTML 文件名来源 |
| tpl | 是 | 固定 `cover_split`（闭集） |
| img | 是 | 右侧图（竖构图优先，人物/产品特写） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题（118px） |
| en | 是 | 金色英文副题 |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| corner | 否 | 右下角标注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 左右 60/40，不用 50/50（专家报告 Topic 5.1）
- 分界线用 2px 金线，不用生硬色块拼接
- 右图与文字无重叠，不用 scrim（与 cover 的压字逻辑区分）
- 配色走主题令牌，不许在字段里写色值
- 字号走 var(--fs-*) 档位

程序/页面生成.py `t_cover_split`
