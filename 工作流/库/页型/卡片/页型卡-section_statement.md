# 页型卡-section_statement

- id: 页型卡-section_statement
- 卡型: 页型卡
- 标题: 章节页（金句落锤式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。不把章节名当标题，而把本章核心观点写成一句话大字居中，角落标注章节编号。观点驱动型演讲/课程/发布会。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| sub | 是 | 一句解释（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- title 为强结论 ≤18 个中文字符；sub 解释 ≤30 字
- 中立性报告（年报/审计）禁用；章节无明确主张时禁用
- 引用他人观点必须注明出处
- 章节页信息密度铁律：只允许编号+标题+一句解释；bullet、正文、图表一律禁止

## 模板对应

程序/页面生成.py `t_section_statement`
