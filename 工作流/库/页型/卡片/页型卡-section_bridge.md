# 页型卡-section_bridge

- id: 页型卡-section_bridge
- 卡型: 页型卡
- 标题: 章节页（引导过渡式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。编号 + ≥60pt 大标题 + 一句承上启下的引导语，配线条/渐变视觉符号。职场汇报、章节逻辑递进时。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| sub | 是 | 引导语（如“接下来我们将探讨…”，≤30 字，弱化） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 标题 ≥60pt；引导语 28pt 左右、90% 不透明度弱化，不喧宾夺主
- 标题本身已是完整观点时禁用（引导语多余）
- 垂直居中，大 padding 保证呼吸感
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

程序/页面生成.py `t_section_bridge`
