## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 C3-大字报），HTML 文件名来源 |
| tpl | 是 | 固定值（闭集） |
| img | 是 | 封面主图（素材文件名） |
| img2 | 是 | 融合叠加图（素材文件名，双重曝光用） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题 |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| corner | 否 | 右下角标注（通用字段，各主题自定） |

## 纪律

- img2 以 mix-blend 融入 img；文字放在融合后的平静区域
- 融合后双方可读性都下降时打回；正式商务禁用
- PPTX 近似：img2 以 alpha=55 叠加（图片组件已扩展 alpha 参数）
