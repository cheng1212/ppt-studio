# 页型卡-section_icon

- id: 页型卡-section_icon
- 卡型: 页型卡
- 标题: 章节页（图标印章式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。中央大图标 + 章节编号 + 标题，浅色底居中，仪式感轻。课程章节、轻量培训 deck。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| icon | 是 | 图标名（见程序/图标.py） |
| sub | 否 | 一句话副标题（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- icon 必须在程序/图标.py 闭集中；图标单用、放大做视觉焦点
- 图标风格全套统一（同为线性或同为面性）
- 正式商务汇报慎用；PPTX 导出时图标省略，由编号承载信息
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

## 模板对应

程序/页面生成.py `t_section_icon`
