# 页型卡-statement_dotdash

- id: 页型卡-statement_dotdash
- 卡型: 页型卡
- 标题: 点线式（分论点＋论据缩进）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

分论点＋论据的支撑页：2–4 个分论点，各带 0–4 条论据。bullet 实心圆点领分论点，
dash 短横领论据并缩进，视觉层次一眼可辨。适合论据较多、需要逐条列举的观点页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `statement_dotdash`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 结论句（完整结论句） |
| items | 是 | 数组，2–4 项；每项：b（分论点，必填）/ ds（论据字符串数组，选填）；单个 bullet 下 ds ≤ 4 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- title 必须是完整结论句，不许话题式标题。
- items 必须为 2–4 项（校验闸拦截）；单个 bullet 下 ds 不得超过 4 条。
- ds 论据必须逐条直接支撑 b，不许在同一 bullet 下混入两个话题。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_statement_dotdash`；PPTX 声明式映射见 程序/pptx映射.py（映射表同名条目）
