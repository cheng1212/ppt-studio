# 页型卡-framework_hub

- id: 页型卡-framework_hub
- 卡型: 页型卡
- 标题: 枢纽辐射
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

中心概念＋辐射节点的框架页：中心圆放 hub，4–6 个 spokes 节点环绕/阵列，
连线相连。适合概念框架、生态图、能力模型、"一个中心＋N 支撑"的表达。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `framework_hub`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题 |
| hub | 是 | 中心名（中心圆） |
| spokes | 是 | 数组，4–6 项；每项：t（节点名，必填）/ d（说明，选填） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- spokes 必须为 4–6 项（校验闸拦截）；节点名必须短，不许长句进节点。
- hub 必须是一个概念/实体，不许话题式短语；连线必须真实表达归属关系，不许装饰性连线。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_framework_hub`；PPTX 声明式映射见 程序/pptx映射.py `映射表["framework_hub"]`
