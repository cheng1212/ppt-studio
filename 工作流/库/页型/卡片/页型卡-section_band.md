# 页型卡-section_band

- id: 页型卡-section_band
- 卡型: 页型卡
- 标题: 章节页（图片横带式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。中部一条横向图片带（约 1/3 页高）+ 留白标题区。章节多、需轻量分隔的长报告。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| img | 是 | 图片带配图（素材文件名，与章节主题呼应） |
| sub | 否 | 一句话副标题（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 图片带高度约 30–45% 页高，上下可用细线收边
- 标题区大量留白，标题 40pt+
- 本质是轻量版全出血图，信息层级相同但视觉重量减半
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

## 模板对应

程序/页面生成.py `t_section_band`
