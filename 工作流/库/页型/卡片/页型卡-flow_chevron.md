# 页型卡-flow_chevron

- id: 页型卡-flow_chevron
- 卡型: 页型卡
- 标题: 箭形管道
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案
- 版式族: 流程

## 适用场景

线性阶段流程：3–5 个首尾咬合的箭形段，如"获客→转化→留存→复购""需求→设计→开发→测试→上线"。
横向箭形段；每段一色、标题白字；段内描述只留关键词。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `flow_chevron`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| steps | 是 | 数组，3–5 项；每项：t（阶段名，必填）/ d（描述，选填，只留关键词） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- steps 必须为 3–5 项（校验闸拦截）；段内 d 只留关键词，长句改用 flow_branch 或正文页。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_flow_chevron`；PPTX 声明式映射见 程序/pptx映射.py `映射表["flow_chevron"]`
