# 页型卡-number_hero

- id: 页型卡-number_hero
- 卡型: 页型卡
- 标题: 大数字（一页一个数字做视觉锤）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 定稿（2026-10-06）

## 适用场景

全页只讲一个数字：200px 金色大数字居中，配说明与上下文。
适合融资路演的"本轮融资目标"、发布会的"核心数字"、总结的"年度关键词"页。
一页只许一个主角数字，第二个数字出现就换页型。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `number_hero`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| v | 是 | 大数字（字符串，如 "5,000万"、"128%"） |
| label | 是 | 数字说明（大数字下方标题字） |
| d | 否 | 补充说明（ muted 小字） |
| ctx | 否 | 上下文行（绿色强调，如"领投方已定，开放跟投"；数字无比较=噪音，有比较才写） |
| icon | 否 | 顶部图标（图标库中文名，`程序/图标.py --列表`；不写则无图标） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- v 尽量短：数字+单位，不超过 8 字；label 是完整语义（"本轮融资目标"而非"融资"）。
- ctx 是"数字的比较/出处"：同比、环比、出处，无比较不写（数字无比较=噪音）。
- 图标在 PPTX 声明式导出中省略，不承载关键信息。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_number_hero`；PPTX 声明式映射见 程序/pptx映射.py `映射表["number_hero"]`
