# 页型卡-org_chart

- id: 页型卡-org_chart
- 卡型: 页型卡
- 标题: 组织架构（树形层级）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

讲"层级汇报关系"：组织架构、决策链条。2–4 层级，根节点在上，
层间连线；每层节点横向排列。区别于 framework_hub（枢纽辐射无上下级语义）。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `org_chart`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题 |
| tiers | 是 | 数组的数组；每层节点名数组（字符串），2–4 层；如 [["CEO"],["CTO","CFO","COO"]] |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 层级 2–4 层，单层节点 ≤6；超了拆页或分组。
- 节点名 ≤10 字；只写汇报关系，不许把职责描述塞进节点。
- 无上下级语义的发散关系改用 framework_hub。

## 模板对应

程序/页面生成.py `t_org_chart`；PPTX 声明式映射见 程序/pptx映射.py `映射表["org_chart"]`
