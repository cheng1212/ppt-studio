# 页型卡-toc_split

- id: 页型卡-toc_split
- 卡型: 页型卡
- 标题: 目录（左右分栏式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。左 1/3 为目录标题区（大字“目录/CONTENTS”+装饰），右 2/3 纵向排列条目。正式汇报万能版式。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，3–5 项；每项：no（编号）/ zh（章节标题）/ desc（一句话描述） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 左右比例约 4:6 或 1:2，禁用 5:5
- 左侧标题区配竖线/色块/大数字装饰
- 右侧条目沿用数字列表规则

## 模板对应

程序/页面生成.py `t_toc_split`
