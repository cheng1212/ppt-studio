# 页型卡-cta_single

- id: 页型卡-cta_single
- 卡型: 页型卡
- 标题: 单一行动
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

收尾行动页：action 超大字居中，下方 who/when/ask 三行小字。适合决策汇报、
立项汇报的最后一页——走出会议室只记住这一件事。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `cta_single`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| action | 是 | 一个行动句（超大字，动词开头） |
| who | 是 | 责任人 |
| when | 是 | 截止时间 |
| ask | 否 | 需要的决策/资源 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 只给 ONE action：action 必须是一个行动句，不许并列两个及以上行动（校验闸拦截）。
- 结尾页不引入新论点/数据：action 必须是前文已论证结论的落地，不许出现新数字。
- action 必须动词开头。
- 配色走主题令牌，不许在字段里写色值。

程序/页面生成.py `t_cta_single`；PPTX 声明式映射见 程序/pptx映射.py `映射表["cta_single"]`
