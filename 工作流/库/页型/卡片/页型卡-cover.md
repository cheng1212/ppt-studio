# 页型卡-cover

- id: 页型卡-cover
- 卡型: 页型卡
- 标题: 封面（满版图压字）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿

## 适用场景

整套课件的第 1 页。满版背景图 + 左侧压字，定调。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 P1-封面），HTML 文件名来源 |
| tpl | 是 | 固定 `cover`（闭集） |
| bg | 是 | 素材文件名（满版背景，cover 铺陈） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题（118px） |
| en | 是 | 金色英文副题 |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| corner | 否 | 右下角标注（通用字段，各主题自定；sodium 用 `Na 11`） |

## 纪律

- 背景图必须是场景图（cover 铺陈）；主体压字区用 scrim 渐变保证可读
- 配色走主题令牌，不许在字段里写色值

## 模板对应

程序/页面生成.py `t_cover`

## 罩子自适应（2026-10-05）

封面罩按主题 `--bg` 亮度自动切换：浅底主题用浅色雾面罩（左实右透）+ 深色字，与内页同语言；深底主题保持深色罩 + 浅色字。老项目渲染不受影响。
