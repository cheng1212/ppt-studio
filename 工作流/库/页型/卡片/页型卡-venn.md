# 页型卡-venn

- id: 页型卡-venn
- 卡型: 页型卡
- 标题: 交集图（2–3 圆 Venn）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

讲"集合间重叠关系"：能力交集、市场重叠、共识区。2–3 个圆交叠，
每个圆有集名；交集区必须标注（区名＋一句话说明），无标注的 Venn 是装饰。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `venn`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，点出交集的意义） |
| sets | 是 | 数组，2–3 项；每项：label（集名） |
| zones | 是 | 数组，1–4 项；每项：label（区名，如"A∩B"）/ d（说明） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 圆 ≤3 个；交集区必须有标注，无意义的装饰圆禁入。
- title 要点出交集的意义，不许只写"Venn 图"。

## 模板对应

程序/页面生成.py `t_venn`；PPTX 声明式映射见 程序/pptx映射.py `映射表["venn"]`
