# 页型卡-definition_terms

- id: 页型卡-definition_terms
- 卡型: 页型卡
- 标题: 术语卡片
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

一组 2–4 个术语的定义页：横向 2–4 张卡片，每张术语加粗＋一句话定义，
统一句式。适合开场统一术语、概念密集章节的术语表页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `definition_terms`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（如"核心术语"） |
| terms | 是 | 数组，2–4 项；每项：t（术语，必填）/ d（一句话定义，必填） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- terms 必须为 2–4 项（校验闸拦截）；每张卡统一句式。
- d 必须是一句话定义，不许两句以上；5 个以上术语改用附录，不许塞进一页。
- title 只许点明这是术语集，不许塞入结论句。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_definition_terms`；PPTX 声明式映射见 程序/pptx映射.py `映射表["definition_terms"]`
