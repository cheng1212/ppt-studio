# 页型卡-statement_golden

- id: 页型卡-statement_golden
- 卡型: 页型卡
- 标题: 金句独白
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

一页只放一句核心主张的金句页：phrase 4–7 词，居中或左下超大字，大量留白。
适合开场定调、章节高光、结尾收束的情绪/观点页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `statement_golden`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| phrase | 是 | 4–7 词核心主张（超大字） |
| sub | 否 | 一句语境说明（小字） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 一页只放这一句：不许叠加图表、清单、双金句（校验闸拦截：除 sub 外不许出现第二主张）。
- phrase 必须是一个可被记住的完整主张，不许话题式短语。
- sub 只许一句语境，不许展开论证。
- 配色走主题令牌，不许在字段里写色值。
