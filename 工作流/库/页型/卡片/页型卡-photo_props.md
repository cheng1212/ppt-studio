# 页型卡-photo_props

- id: 页型卡-photo_props
- 卡型: 页型卡
- 标题: 图文性质页（左图右色块标签行 + 结论条）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿
- 版式族: 图文

## 适用场景

讲"性质/特征"类知识页：左图，右为色块标签行（发丝线分隔），底部金边结论条收束。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `photo_props`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| img | 否 | 左图素材文件名 |
| tag | 否 | 图角标（可用 `<b>` 标金） |
| cap | 否 | 图注 |
| rows | 是 | 数组；每项：b（色块色：闭集 ink/green/gold/ox，ox=氧化橙语义色）/ k（标签词）/ n（要点，可用 `<em>` 标绿）/ d（说明） |
| concl | 是 | 金边结论条（可用 `<b>` 标绿） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |


> 无图说明：img/tag/cap 为选填。无图时模板走纯文字分支，且须经 `--无图 "理由"` 显式放行（配图偏好软闸，见 _步.json P1）。

## 纪律

- 知识页禁止裸列表：色块标签 + 结论条是标配，每件须答得出「去掉它损失什么信息」
- 实物特写图 contain 完整显示（裁切斩断主体 = 事故）；场景图才 cover
- rows 建议 3–5 行，超了拆页

## 模板对应

程序/页面生成.py `t_photo_props`
