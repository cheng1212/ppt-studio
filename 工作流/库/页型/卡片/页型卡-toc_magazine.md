# 页型卡-toc_magazine

- id: 页型卡-toc_magazine
- 卡型: 页型卡
- 标题: 目录（杂志索引式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。模仿杂志目录：条目配引导线（dot leader）+ 页码/序号，编辑感强。年度报告/白皮书/作品集。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，4–6 项；每项：no（编号/页码）/ zh（章节标题） |
| items[].desc | 否 | 一句话描述 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 引导线必须对齐；字号层级严格（章 18–20pt / 节 14pt）
- 中英混排字体统一
- 短平快口头汇报慎用

## 模板对应

程序/页面生成.py `t_toc_magazine`
