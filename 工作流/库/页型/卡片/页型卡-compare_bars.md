# 页型卡-compare_bars

- id: 页型卡-compare_bars
- 卡型: 页型卡
- 标题: 对比条（两组数据横向条形对比）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 定稿（2026-10-06）
- 版式族: 对比

## 适用场景

同一批对象在两组数据下的横向对比：每行一个对象，两条条形（a 组金色强调、
b 组灰色），条宽按全部数值极值归一化。适合"今年 vs 去年""我方 vs 竞品"、
"目标 vs 实际"类对比页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `compare_bars`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| rows | 是 | 数组，1–6 行；每行：label（对象名，必填）/ a（a 组数值，数字，必填）/ b（b 组数值，数字，必填） |
| a_name | 否 | a 组名（表头，缺省 "A"） |
| b_name | 否 | b 组名（表头，缺省 "B"） |
| concl | 否 | 结论条（沉底通栏，可用 `<b>` 标金） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- rows 必须为 1–6 行（校验闸拦截）；a/b 必须为数字（校验闸拦截），条宽按极值归一化，非数字无法归一化。
- a 组永远是"要强调的那组"（金色条）：今年/我方/目标放 a，去年/竞品/实际放 b。
- 行数超过 6 行改用 table_compare；只有 1 组数据改用 chart。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_compare_bars`；PPTX 声明式映射见 程序/pptx映射.py `映射表["compare_bars"]`
