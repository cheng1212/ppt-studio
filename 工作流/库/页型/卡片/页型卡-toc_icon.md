# 页型卡-toc_icon

- id: 页型卡-toc_icon
- 卡型: 页型卡
- 标题: 目录（图标式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。每项配线性图标（图标+大编号双锚点）+ 标题 + 短描述。抽象议题快速传达属性。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，4–6 项；每项：no（编号）/ zh（章节标题）/ desc（一句话描述）/ icon（图标名，见程序/图标.py） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- icon 必须在程序/图标.py 闭集中；找不到贴切图标时禁用此页型
- 图标风格统一（同为线性、尺寸 40–64px），图标色 = 主题色
- PPTX 导出时图标省略，由大编号承载信息

## 模板对应

程序/页面生成.py `t_toc_icon`
