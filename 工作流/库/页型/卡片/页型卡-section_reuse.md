# 页型卡-section_reuse

- id: 页型卡-section_reuse
- 卡型: 页型卡
- 标题: 章节页（目录复用高亮式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页（BCG 式）。不做独立章节页：重现目录，当前章节高亮、其余弱化。咨询报告、长篇正式汇报。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| current | 是 | 当前章节序号（1 起，1 ≤ current ≤ items 数） |
| items | 是 | 数组；每项：no（编号）/ zh（章节名） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 与目录页共享同一编号体系、同一视觉语言
- 当前章品牌深色加粗 + 左侧色条；非当前章中灰常规字重
- 演讲型/情绪型 deck 慎用；章节 <3 时禁用
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

程序/页面生成.py `t_section_reuse`
