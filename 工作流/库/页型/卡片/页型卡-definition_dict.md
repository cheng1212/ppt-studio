# 页型卡-definition_dict

- id: 页型卡-definition_dict
- 卡型: 页型卡
- 标题: 词典条目式
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

一页只定义一个词的术语页：term 左上巨大加粗，规则线/冒号分隔，def 干净小字，
note 写边界说明（包含什么/不包含什么）。适合全篇统一口径、消除歧义的定义页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `definition_dict`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| term | 是 | 术语（左上巨大加粗） |
| def | 是 | 一句话定义（干净小字） |
| en | 否 | 英文原词 |
| note | 否 | 边界说明：包含/不包含什么 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 一页只定义一个词（校验闸拦截：term 不许出现枚举多词）。
- def 必须是一句话，不许展开成段落；超长说明拆到 note。
- term 与 def 之间用规则线/冒号分隔，视觉上必须是"词典条目"读法。
- 配色走主题令牌，不许在字段里写色值。
