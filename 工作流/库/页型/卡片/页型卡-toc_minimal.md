# 页型卡-toc_minimal

- id: 页型卡-toc_minimal
- 卡型: 页型卡
- 标题: 目录（极简文字式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。无编号/图标/图片，仅靠字号/字重/灰度层级排布大标题，留白极大。设计工作室/艺术类/极简品牌。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| sub | 否 | 副标题（极简版式可省略） |
| items | 是 | 数组，3–5 项；每项：zh（章节标题） |
| items[].no | 否 | 编号（可省略，纯文字目录） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 标题 32–48pt；页面留白 ≥40%，“空”不可变“寒酸”
- 用灰度区分主次；全页只用一种对齐（左对齐或居中二选一）
- 信息型汇报慎用（观众需要编号定位进度）

## 模板对应

程序/页面生成.py `t_toc_minimal`
