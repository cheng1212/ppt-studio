# 页型卡-chart_dashboard

- id: 页型卡-chart_dashboard
- 卡型: 页型卡
- 标题: 图表页（仪表盘）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 数据

## 适用场景

顶部 3–6 张 KPI 卡片（大数字 + 同比箭头 + sparkline），下方 1–2 个支撑图表。月报/季报首页、现状总览。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `04 / 18`） |
| kick | 是 | 眉题（如 `SALES / 销量`） |
| title | 是 | 结论式标题（Action Title：完整结论句，不是话题） |
| img | 是 | 图表 PNG（程序/图表.py 生成，素材文件名） |
| cap | 是 | 图注：数据来源 + 口径/期间（不可省略） |
| foot | 是 | 底部左注 |
| kpis | 是 | 数组；每项：名（指标名）/ 值（大数字）/ 变化（如 `+12.5%`，含方向） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |

## 纪律

- 卡片 3–6 张等分；涨跌好坏用语义色但必须配箭头符号（色盲安全）
- 下方图表与卡片指标一一对应
- 仪表盘只呈现状态不呈现论证；需要讲因果时拆页
- 标题铁律：title 必须是完整结论句（++），只读各页标题能串成故事；话题式标题禁用

## 模板对应

程序/页面生成.py `t_chart_dashboard`
