# 页型卡-quote_full

- id: 页型卡-quote_full
- 卡型: 页型卡
- 标题: 全幅引言
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

全屏引言页：巨大引号装饰＋引文大字居中＋细线分隔作者行。适合章节开场、
观点背书、权威引用的氛围页。bgimg 全幅图时文字区加半透明框压住。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `quote_full`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| quote | 是 | 引文全文 |
| author | 是 | 作者＋身份 |
| source | 否 | 出处（书/演讲/时间等） |
| bgimg | 否 | 全幅背景图；有 bgimg 时文字区加半透明框压住 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集；bgimg 时一般不叠加） |

## 纪律

- 一页只放一条引用。
- quote 必须原样引用，不许断章取义、篡改措辞；必须给出可查证的出处线索。
- bgimg 只是氛围衬底，不许喧宾夺主抢走引文主体。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_quote_full`；PPTX 声明式映射见 程序/pptx映射.py `映射表["quote_full"]`
