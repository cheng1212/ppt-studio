# 页型卡-toc_tabs

- id: 页型卡-toc_tabs
- 卡型: 页型卡
- 标题: 目录（横向条带式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。条目做成横向色带/标签阶梯排列，形似导航标签页。科技/互联网风格。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，3–5 项；每项：no（编号）/ zh（章节标题，2–6 字） |
| items[].desc | 否 | 一句话描述（条带空间有限，慎用） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 标题须极短（2–6 字），长标题禁用此页型
- 条带等高、等距；颜色不超过 2 种
- 首项可用主题色填充、其余描边或浅底

## 模板对应

程序/页面生成.py `t_toc_tabs`
