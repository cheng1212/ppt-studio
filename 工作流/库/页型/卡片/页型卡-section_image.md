# 页型卡-section_image

- id: 页型卡-section_image
- 卡型: 页型卡
- 标题: 章节页（全出血图片式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。整页铺满高清主题图，编号与标题压在遮罩上。发布会、品牌故事等需要情绪铺垫的场合。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| img | 是 | 全幅背景图（素材文件名，高清且与章节主题相关） |
| sub | 否 | 一句话副标题（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 图片必须高清、无水印、与章节主题相关；低质图禁用此页型
- 文字区必须加遮罩（短标题低透明色块透图，长文字黑底 ~50% 垫底）
- 标题优先放在图片留白/暗部处
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

## 模板对应

程序/页面生成.py `t_section_image`
