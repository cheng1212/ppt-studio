# 页型卡-toc_image

- id: 页型卡-toc_image
- 卡型: 页型卡
- 标题: 目录（图片驱动式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。全幅大图背景 + 定向渐变蒙版，条目白字压在蒙版上。发布会/品牌提案氛围优先场合。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| img | 是 | 背景大图（素材文件名，须高清且与主题相关） |
| items | 是 | 数组，≤5 项；每项：no（编号）/ zh（章节标题） |
| items[].desc | 否 | 一句话描述 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 图片必须高清；低清拉伸图禁用此页型
- 蒙版用“图片→透明→深色”定向渐变，文字侧加深
- 文字纯白 + 轻微阴影；条目只放关键词

## 模板对应

程序/页面生成.py `t_toc_image`
