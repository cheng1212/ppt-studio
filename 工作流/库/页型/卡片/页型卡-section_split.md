# 页型卡-section_split

- id: 页型卡-section_split
- 卡型: 页型卡
- 标题: 章节页（左右分栏式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。40–50% 图片侧 + 文字侧（编号+标题+一句话说明）。企业汇报、产品方案类 deck。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| img | 是 | 图片侧配图（素材文件名，与章节主题相关） |
| sub | 是 | 一句话说明（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 图片侧占 40–50%，文字侧深色或纯色保证对比
- 无合适图片时禁用此页型（硬塞装饰图即廉价）
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

## 模板对应

程序/页面生成.py `t_section_split`
