# 页型卡-section_minimal

- id: 页型卡-section_minimal
- 卡型: 页型卡
- 标题: 章节页（极简留白式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。浅色底巨型标题居中/左对齐，四周大量留白，几乎零装饰。杂志风/编辑风 deck。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| sub | 否 | 一句话副标题（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 标题 36–48pt；内容严格控制在页面中央 70% 区域内
- 背景忌纯白（可用纸感色）；除标题外最多允许一条细分割线
- 需要情绪动员的演讲开场慎用
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

## 模板对应

程序/页面生成.py `t_section_minimal`
