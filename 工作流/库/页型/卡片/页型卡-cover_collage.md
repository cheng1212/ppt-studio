## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 C3-大字报），HTML 文件名来源 |
| tpl | 是 | 固定值（闭集） |
| imgs | 是 | 拼贴图数组（2–4 项）；子字段：src（见规约 imgs必填） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题 |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| corner | 否 | 右下角标注（通用字段，各主题自定） |

## 纪律

- imgs 2–4 项；图片统一色调/处理；网格间距一致
- 标题放在干净色块带上，不直接压在拼缝上
- 只需要一个核心信息时禁用（拼贴会分散注意力）
