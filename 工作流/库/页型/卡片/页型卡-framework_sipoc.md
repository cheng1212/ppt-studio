- 来源轨: 库内装配

- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

流程界定页：横向五列（供应商→输入→流程→输出→客户），列头＋条目纵向排布，
一页说清"谁给什么、经什么流程、产出什么、给谁"。适合流程梳理、职责界定页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `framework_sipoc`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题 |
| suppliers | 是 | 字符串数组，2–6 项：供应商 |
| inputs | 是 | 字符串数组，2–6 项：输入 |
| process | 是 | 字符串数组，2–6 项：流程 |
| outputs | 是 | 字符串数组，2–6 项：输出 |
| customers | 是 | 字符串数组，2–6 项：客户 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 五列各必须为 2–6 项字符串数组（校验闸拦截）；条目必须是名词/名词短语，不许长句。
- 列间逻辑闭环：outputs 必须能对应到 customers 的需求，不许五列各自为政。
- 配色走主题令牌，不许在字段里写色值。
