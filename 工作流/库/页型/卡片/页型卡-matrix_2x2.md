# 页型卡-matrix_2x2

- id: 页型卡-matrix_2x2
- 卡型: 页型卡
- 标题: 2×2 矩阵
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案
- 版式族: 对比

## 适用场景

双维度四象限定位：按 x/y 两轴把条目落位到四个象限，如"重要性×紧急性""投入×产出"。
每个象限有命名和默认动作，条目落位有明确依据；2×2 网格＋轴标签＋象限名＋条目。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `matrix_2x2`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| x_axis | 是 | x 轴名＋方向（如"投入（低→高）"） |
| y_axis | 是 | y 轴名＋方向（如"产出（低→高）"） |
| quads | 是 | 数组，4 项；每项：n（象限名，必填）/ d（说明/默认动作，选填）/ items（落位条目数组，选填） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 轴无标签/象限无命名的装饰九宫格禁入：两轴必须有名、四个象限必须命名。
- quads 必须恰为 4 项（校验闸拦截）。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_matrix_2x2`；PPTX 声明式映射见 程序/pptx映射.py `映射表["matrix_2x2"]`
