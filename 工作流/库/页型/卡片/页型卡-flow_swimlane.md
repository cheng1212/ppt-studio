# 页型卡-flow_swimlane

- id: 页型卡-flow_swimlane
- 卡型: 页型卡
- 标题: 泳道图
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案
- 版式族: 流程

## 适用场景

跨角色/部门的协作流程：2–4 条横向泳道，每条泳道归属一个角色/部门；
步骤盒按泳道落位，交接处用跨道箭头表示，如"下单→审核→发货→签收"的责任分工。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `flow_swimlane`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| lanes | 是 | 数组，2–4 条；每条：role（角色/部门，必填）/ steps（步骤字符串数组，必填） |
| note | 否 | 补充说明（如交接规则、例外路径） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 活动不许悬浮在泳道之外、归属不明：每个步骤必须落到一条泳道。
- 配色走主题令牌，不许在字段里写色值。

程序/页面生成.py `t_flow_swimlane`；PPTX 声明式映射见 程序/pptx映射.py `映射表["flow_swimlane"]`
