# 页型卡-toc_list

- id: 页型卡-toc_list
- 卡型: 页型卡
- 标题: 目录（数字列表式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。纵向编号行：每行 = 大编号 + 标题 + 一句话描述，行间细线分隔。正式汇报最稳妥的目录版式。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，3–6 项；每项：no（两位编号如 `01`）/ zh（章节标题）/ desc（一句话描述） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- items 3–6 项；超过 6 项须合并、分组或拆页
- 编号用 `01/02` 两位数字，字号约为标题的 1.4–1.6 倍，主题色加粗
- 行间用 1px 分隔线或间距制造节奏，二选一不叠加

## 模板对应

程序/页面生成.py `t_toc_list`
