# 页型卡-chart_combo

- id: 页型卡-chart_combo
- 卡型: 页型卡
- 标题: 图表页（组合双轴）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 数据

## 适用场景

柱（绝对值，主轴）+ 线（比率，次轴）叠于同一 X 轴，如销量（柱）+ 渗透率（线）。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `04 / 18`） |
| kick | 是 | 眉题（如 `SALES / 销量`） |
| title | 是 | 结论式标题（Action Title：完整结论句，不是话题） |
| img | 是 | 图表 PNG（程序/图表.py 生成，素材文件名） |
| cap | 是 | 图注：数据来源 + 口径/期间（不可省略） |
| foot | 是 | 底部左注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |

## 纪律

- 唯一正当场景：两量纲不同但真实配对的指标，故事是一升一降/量价背离
- 仅 2 个系列；轴色与系列色绑定；次轴刻度必须诚实（不得调刻度制造交叉假象）
- 无实质关联硬凑双轴 = 伪造相关性，禁用
- 标题铁律：title 必须是完整结论句（++），只读各页标题能串成故事；话题式标题禁用

## 模板对应

程序/页面生成.py `t_chart_combo`
