# 页型卡-toc_curve

- id: 页型卡-toc_curve
- 卡型: 页型卡
- 标题: 目录（曲线路径式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。条目沿 S 形曲线排布，节点左右交错。中文设计圈处理 5–6 条目目录的救场技法。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，5–6 项；每项：no（编号）/ zh（章节标题）/ desc（一句话描述） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- items 固定 5–6 项；≤4 项禁用此页型（曲线无必要）
- 节点沿曲线等距，文字左右交错防拥挤
- 正式严肃场合慎用

## 模板对应

程序/页面生成.py `t_toc_curve`
