# 页型卡-testimonial

- id: 页型卡-testimonial
- 卡型: 页型卡
- 标题: 证言式
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案
- 版式族: 图文

## 适用场景

单条客户/专家证言：左肖像（圆形/圆角），右大引号＋引文＋署名＋结果数字。
一次只放一条证言。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `testimonial`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| quote | 是 | 证言引文 |
| name | 是 | 姓名/职位/公司 |
| photo | 是 | 肖像图 |
| result | 是 | 一个结果数字＋说明 |
| cap | 否 | 图片说明 |
| mask | 否 | 图片遮罩 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 匿名证言（"某头部客户"）禁入：必须实名＋职位/公司。
- 一次只放一条证言。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_testimonial`；PPTX 声明式映射见 程序/pptx映射.py `映射表["testimonial"]`
