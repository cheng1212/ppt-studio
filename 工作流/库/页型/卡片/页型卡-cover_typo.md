# 页型卡-cover_typo

- id: 页型卡-cover_typo
- 卡型: 页型卡
- 标题: 封面（大字报式纯文字）
- 来源轨: 封面版式深调研 encoding（2026-10-06，16 版式分类）
- 生产者: chengge
- 状态: 草案
- 版式族: 封面

## 适用场景

发布会 Keynote、宣言式主题；标题短而有力、无好图可用时。文字即图形，零图片依赖。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 C3-大字报），HTML 文件名来源 |
| tpl | 是 | 固定值（闭集） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题 |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| en | 否 | 英文副题 |
| corner | 否 | 右下角标注（通用字段，各主题自定） |

## 纪律

- 无图封面；标题走 --fs-hero（96px），长标题必须拆行，关键词可用 <b> 标强调色
- 背景只许纯色或极淡纹理；全页字体≤2种
- PPTX：底色+文本直出，与 HTML 一致
