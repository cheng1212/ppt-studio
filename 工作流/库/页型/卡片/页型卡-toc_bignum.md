# 页型卡-toc_bignum

- id: 页型卡-toc_bignum
- 卡型: 页型卡
- 标题: 目录（大字数字式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。`01/02` 放大到 60–120pt 做视觉主体，标题叠印或并排。中文设计圈“数字目录”，高级感首选。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，3–4 项；每项：no（编号）/ zh（章节标题）/ desc（一句话描述） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- items 3–4 项；≥6 项禁用此页型
- 数字用超粗无衬线，可浅色叠印做背景装饰（透明度 10–15%）
- 数字与标题不可同字号同颜色，主次必须分明

## 模板对应

程序/页面生成.py `t_toc_bignum`
