# 页型卡-toc_tb

- id: 页型卡-toc_tb
- 卡型: 页型卡
- 标题: 目录（上下分割式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。上部为标题横幅区（通栏色块/图片），下部条目横向 3–4 列排布。适配 16:9 宽幅。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| items | 是 | 数组，3–4 项；每项：no（编号）/ zh（章节标题）/ desc（一句话描述） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- items 3–4 项；≥5 项禁用此页型
- 上部横幅高约 30–35%，不可喧宾夺主
- 下部每列等宽、顶部对齐，列间用竖线或留白分隔

## 模板对应

程序/页面生成.py `t_toc_tb`
