# 页型卡-closing_qa

- id: 页型卡-closing_qa
- 卡型: 页型卡
- 标题: 致谢＋问答
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

结尾页：thanks 大字致谢、contact 醒目联系方式、seeds 2–3 个种子问题暖场、
takeaway 一句话核心回顾金句条；Q&A 留屏供拍照。适合汇报/演讲的最后一页
（致谢＋联系＋引导式问答合并）。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `closing_qa`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| thanks | 是 | 致谢标题（大字，如"谢谢"） |
| contact | 是 | 联系方式（醒目条） |
| seeds | 否 | 字符串数组，2–3 个种子问题 |
| takeaway | 否 | 一句话核心回顾（金句条） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- Q&A 留屏页不引入新论点/数据：seeds 只许是开放性问题，takeaway 只能是前文
  结论的复述，不许出现新数字新主张。
- seeds 不得超过 3 个（校验闸拦截）；contact 必须真实有效，不许占位符。
- 配色走主题令牌，不许在字段里写色值。
