# 页型卡-chart_map

- id: 页型卡-chart_map
- 卡型: 页型卡
- 标题: 图表页（地图页）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 数据

## 适用场景

分级设色地图：区域渗透、市场覆盖、省际对比。地理位置本身就是故事时使用。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `04 / 18`） |
| kick | 是 | 眉题（如 `SALES / 销量`） |
| title | 是 | 结论式标题（Action Title：完整结论句，不是话题） |
| img | 是 | 图表 PNG（程序/图表.py 生成，素材文件名） |
| cap | 是 | 图注：数据来源 + 口径/期间（不可省略） |
| foot | 是 | 底部左注 |
| metric | 是 | 指标口径（如 `新能源渗透率（%）`，必须写清口径） |
| note | 否 | 补充说明 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |

## 纪律

- 填色指标必须用比率/人均/指数类（画总量 = 重画人口地图，禁用）
- 无数据 ≠ 0，必须用中性色区分
- 当前状态：地理边界数据未接入，渲染为占位；不得用于正式交付
- 标题铁律：title 必须是完整结论句（++），只读各页标题能串成故事；话题式标题禁用

## 模板对应

程序/页面生成.py `t_chart_map`
