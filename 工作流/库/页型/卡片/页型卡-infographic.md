# 页型卡-infographic

- id: 页型卡-infographic
- 卡型: 页型卡
- 标题: 信息图（图标+数字+说明，2–4 项横向卡片）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 定稿（2026-10-06）

## 适用场景

一页讲 2–4 个并列亮点：每项一个图标 + 大数字 + 标签 + 一句话说明，
横向卡片排布。适合融资路演的"成绩单"页、年度总结的"关键战果"页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `infographic`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| items | 是 | 数组，2–4 项；每项：icon（图标库中文名，`程序/图标.py --列表`，缺省"星"）/ v（大数字，必填）/ label（标签，必填）/ d（说明，选填） |
| concl | 否 | 结论条（沉底通栏，可用 `<b>` 标金） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- items 必须为 2–4 项（校验闸拦截）；项数决定卡片宽度，2 项显空、5 项显挤。
- v 是视觉锤：数字优先，文字型 v（如 "Top 3"）不超过 6 字。
- icon 缺省为"星"；图标在 PPTX 声明式导出中省略（组件闭集无图标），数字/标签/说明承载信息。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_infographic`；PPTX 声明式映射见 程序/pptx映射.py `映射表["infographic"]`
