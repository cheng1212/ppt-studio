# 页型卡-chart_annotated

- id: 页型卡-chart_annotated
- 卡型: 页型卡
- 标题: 图表页（标注型）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 数据

## 适用场景

图表内部用数据锚定标注讲 so-what：CAGR 箭头、delta 括号、目标线、区间色带、关键点 callout。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `04 / 18`） |
| kick | 是 | 眉题（如 `SALES / 销量`） |
| title | 是 | 结论式标题（Action Title：完整结论句，不是话题） |
| img | 是 | 图表 PNG（程序/图表.py 生成，素材文件名） |
| cap | 是 | 图注：数据来源 + 口径/期间（不可省略） |
| foot | 是 | 底部左注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |

## 纪律

- 标注必须锚定数据点；每页只标 ONE 事物；标注文字 ≤15 字
- 一页标注超过 1–2 处即噪音；标注与标题结论重复时删标注
- 标注色 = 页面强调色
- 标题铁律：title 必须是完整结论句（++），只读各页标题能串成故事；话题式标题禁用

## 模板对应

程序/页面生成.py `t_chart_annotated`
