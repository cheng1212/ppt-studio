# 页型卡-cover_magazine

- id: 页型卡-cover_magazine
- 卡型: 页型卡
- 标题: 封面（杂志编辑风）
- 来源轨: 封面版式深调研 encoding（2026-10-06，16 版式分类）
- 生产者: chengge
- 状态: 草案
- 版式族: 封面

## 适用场景

个人品牌、文化创意、年度特刊式总结；人物封面。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 C3-大字报），HTML 文件名来源 |
| tpl | 是 | 固定值（闭集） |
| img | 是 | 封面主图（素材文件名） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题 |
| kickers | 是 | 杂志风 kicker 行数组（2–4 条）；子字段：t（见规约 kickers必填） |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| corner | 否 | 右下角标注（通用字段，各主题自定） |

## 纪律

- 主标题可部分被人物遮挡，但前后层级必须明确
- kicker 行 2–4 条、字号小但字重足；顶部放期号/日期式元信息
- 配色克制（常黑白 + 一个点缀色）；正式商务汇报禁用
