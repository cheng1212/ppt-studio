# 页型卡-cta_next

- id: 页型卡-cta_next
- 卡型: 页型卡
- 标题: 下一步清单
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

收尾下一步页：编号清单 ≤3 条行动（行动＋责任人＋时间），contact 底部
联系方式条。适合汇报结尾、方案落地页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `cta_next`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（如"下一步"） |
| steps | 是 | 数组，≤3 项；每项：t（行动，动词开头，必填）/ owner（必填）/ due（必填） |
| contact | 是 | 联系方式（底部联系方式条） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- steps 不得超过 3 项（校验闸拦截）；每项行动必须动词开头。
- owner、due 均为必填；无责任人/时间的伪行动禁入。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_cta_next`；PPTX 声明式映射见 程序/pptx映射.py `映射表["cta_next"]`
