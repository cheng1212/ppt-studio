# 页型卡-photo_chain

- id: 页型卡-photo_chain
- 卡型: 页型卡
- 标题: 图文因果页（左图右编号链 + 提示框）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿
- 版式族: 图文

## 适用场景

讲"因果/流程/方法"类知识页：左图，右为编号圆步骤链（因果箭头连接），底部提示框。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `photo_chain`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| img | 否 | 左图素材文件名 |
| cap | 否 | 图注 |
| steps | 是 | 数组；每项：t（步骤标题）/ d（说明）。步骤间自动加因果箭头 |
| warn | 是 | 底部提示框（可用 `<b>` 标绿） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |


> 无图说明：img/tag/cap 为选填。无图时模板走纯文字分支，且须经 `--无图 "理由"` 显式放行（配图偏好软闸，见 _步.json P1）。

## 纪律

- steps 须是真因果链（后一步由前一步推出），不是并列清单；并列清单用 photo_props
- steps 建议 3–4 步，超了拆页
- warn 放安全/关键提示，不放普通说明

## 模板对应

程序/页面生成.py `t_photo_chain`
