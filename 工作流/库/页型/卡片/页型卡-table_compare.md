# 页型卡-table_compare

- id: 页型卡-table_compare
- 卡型: 页型卡
- 标题: 对比表页（多对象横向对比 + 结论条）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿

## 适用场景

讲"多对象对比"类知识页：表头列 + 若干对比行，首列为对象名（自动标绿加粗），底部金边结论条收束。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `table_compare`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| cols | 是 | 数组；表头列名（字符串数组，2–6 列） |
| rows | 是 | 二维数组；每行长度必须等于 cols 长度；单元格可用 `<b>` 标金、`<em>` 标绿 |
| concl | 是 | 金边结论条（可用 `<b>` 标绿） |
| img | 选填 | 配图文件名；有图时表格收至左 1080px，右 480px 配图（配图偏好：能配就配） |
| cap | 选填 | 配图图注（有 img 时建议填） |
| foot | 是 | 底部右注 |

## 纪律

- 对比维度必须可比：每列是同一属性，跨行可比；不可比的维度不许硬塞进表里
- cols 2–6 列，rows 2–8 行；超了拆页或换页型
- 首列是对象主键列，模板自动标绿加粗，数据里不许再套样式标签抢戏
- 知识页禁止裸列表：结论条是标配，须答得出「去掉它损失什么信息」

程序/页面生成.py `t_table_compare`
