# 页型卡-statement_assertion

- id: 页型卡-statement_assertion
- 卡型: 页型卡
- 标题: 行动标题页
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

结论先行的观点页：标题用一句完整断言说清本页核心结论，副标题交代口径/
范围/读法，下方 2–4 个分论点（可选带论据）纵向支撑。适合每节的第一页、
决策汇报页、"结论在上"的表达。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `statement_assertion`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 断言句（完整结论句，不许话题式标题） |
| sub | 是 | 口径/范围/读法说明，小字灰 |
| points | 是 | 数组，2–4 项；每项：t（分论点，必填）/ d（论据，选填）；分论点加粗、论据缩进小字 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- title 必须是完整结论句，不许话题式标题（校验闸拦截：不许出现纯名词短语标题）。
- points 必须为 2–4 项（校验闸拦截）；d 论据必须直接支撑本项 t，不许跑题。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_statement_assertion`；PPTX 声明式映射见 程序/pptx映射.py（映射表同名条目）
