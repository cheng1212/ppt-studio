# 页型卡-quote_card

- id: 页型卡-quote_card
- 卡型: 页型卡
- 标题: 卡片式引用
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

正文中嵌入引用的页：中央卡片（引号＋引文＋署名＋来源行），point 为顶部
关联论点小字，说明这条引用为哪个论点背书。适合论证流程中的引用页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `quote_card`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| quote | 是 | 引文（≤30 词） |
| by | 是 | 署名 |
| src | 是 | 来源行：谁/何时/何处 |
| point | 否 | 关联论点（顶部小字） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 一页只放一条引用（校验闸拦截：quote 不许出现多引号并列）。
- quote 不得超过 30 词，超长引用改用 quote_full。
- src 必须写明谁/何时/何处，三者缺一不可。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_quote_card`；PPTX 声明式映射见 程序/pptx映射.py `映射表["quote_card"]`
