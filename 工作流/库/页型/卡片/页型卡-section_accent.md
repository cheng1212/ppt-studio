# 页型卡-section_accent

- id: 页型卡-section_accent
- 卡型: 页型卡
- 标题: 章节页（深色强调条式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。深色全出血底 + 品牌色竖条（左侧通高），编号 + 标题左对齐。科技/金融类 deck。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| num | 否 | 大编号（如 `01`；缺省取 kick 末段） |
| sub | 否 | 一句话副标题（≤30 字，灰色弱化） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 强调条只出现一次、只用品牌色；左侧 6pt 宽通高
- 编号 60pt 品牌色，标题 36pt 白色左对齐垂直居中
- 全套浅色编辑风 deck 慎用
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

程序/页面生成.py `t_section_accent`
