# 页型卡-flow_branch

- id: 页型卡-flow_branch
- 卡型: 页型卡
- 标题: 分支流程图（同一起点 → 条件分支 → 不同结果）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿
- 版式族: 流程

## 适用场景

讲"条件分支"类知识页：同一个起点，因条件不同走向不同结果。顶部起点框，分叉线展开 2–4 个分支，每个分支 = 条件徽标 + 结果 + 说明。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `flow_branch`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| root | 是 | 起点；{t（起点名）, d（说明）} |
| branches | 是 | 数组（2–4 项）；每项 {cond（条件徽标词）, result（结果，加粗标绿）, d（说明）} |
| concl | 是 | 金边结论条（可用 `<b>` 标绿） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 分支必须是真分支：同一前提、条件互斥、结果不同；并列清单不许硬套分支图
- branches 2–4 个，超了拆页
- 条件徽标词 ≤ 4 字，结果 ≤ 8 字，超了改文案不放大小字

程序/页面生成.py `t_flow_branch`
