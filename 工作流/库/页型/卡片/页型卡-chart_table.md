# 页型卡-chart_table

- id: 页型卡-chart_table
- 卡型: 页型卡
- 标题: 图表页（图表+数据表）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 数据

## 适用场景

上图讲形态/结论，下表给精确数值。观众需要既看趋势又查数的经营复盘、财务 deck。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `04 / 18`） |
| kick | 是 | 眉题（如 `SALES / 销量`） |
| title | 是 | 结论式标题（Action Title：完整结论句，不是话题） |
| img | 是 | 图表 PNG（程序/图表.py 生成，素材文件名） |
| cap | 是 | 图注：数据来源 + 口径/期间（不可省略） |
| foot | 是 | 底部左注 |
| headers | 是 | 表头（字符串数组，单位在表头注明如“单位：万元”） |
| rows | 是 | 数据行（字符串二维数组，≤5 行 ×4 列） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |
| mask | 否 | 图片蒙版：circle/rounded/blob/arch（闭集，仅有图页型） |

## 纪律

- 表在下、图在上，表宽与图宽对齐；数值右对齐
- 表格只放图表中出现过的口径；超 5 行 ×4 列直接放附录
- 图表已标全数据时二选一（同一数字不说两次）
- 标题铁律：title 必须是完整结论句（++），只读各页标题能串成故事；话题式标题禁用

## 模板对应

程序/页面生成.py `t_chart_table`
