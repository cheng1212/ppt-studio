# 页型卡-flow_cycle

- id: 页型卡-flow_cycle
- 卡型: 页型卡
- 标题: 循环关系图（节点环形排布 + 带标签箭头）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿

## 适用场景

讲"循环转化/关系网络"类知识页：3–6 个节点环形排布，箭头表示转化方向，箭头上标注条件。典型如物质转化关系、循环过程。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `flow_cycle`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| nodes | 是 | 数组（3–6 项）；节点名（字符串，建议用 unicode 下标如 Na₂O） |
| edges | 是 | 数组；每项 {from（起点节点名）, to（终点节点名）, label（箭头标注：反应条件）}；from/to 必须在 nodes 中 |
| concl | 是 | 金边结论条（可用 `<b>` 标绿） |
| foot | 是 | 底部右注 |

## 纪律

- 箭头必须有方向、有标注条件；无条件标注的裸箭头不许出现
- edges 的 from/to 必须命中 nodes，孤立节点（无进无出）不许出现
- 节点名 ≤ 8 字符，label ≤ 8 字符，超了改文案

## 模板对应

程序/页面生成.py `t_flow_cycle`
