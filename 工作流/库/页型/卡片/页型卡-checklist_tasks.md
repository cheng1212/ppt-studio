# 页型卡-checklist_tasks

- id: 页型卡-checklist_tasks
- 卡型: 页型卡
- 标题: 任务清单
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

任务跟进页：纵向清单行（复选框＋事项＋责任人＋时间右对齐）。适合项目例会、
交付计划、行动项跟踪页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `checklist_tasks`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题 |
| tasks | 是 | 数组，3–7 项；每项：t（事项，必填）/ owner（责任人，必填）/ due（时间，必填） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 无责任人/时间的伪清单禁入：owner、due 均为必填（校验闸拦截）。
- tasks 必须为 3–7 项（校验闸拦截）；责任人必须具体到人，不许写"相关部门"。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_checklist_tasks`；PPTX 声明式映射见 程序/pptx映射.py（映射表同名条目）
