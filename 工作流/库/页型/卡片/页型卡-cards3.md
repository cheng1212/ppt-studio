# 页型卡-cards3

- id: 页型卡-cards3
- 卡型: 页型卡
- 标题: 横向三卡片（并列三条横向排布 + 结论条沉底）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 定稿（2026-10-05）
- 版式族: 观点

## 适用场景

并列关系三条内容（如学习目标、易错辨析）：横向三卡片，每卡徽章 + 要点 + 说明，结论条沉底。卡片顶边色随徽章色。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `cards3`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| cards | 是 | 数组，固定 3 项；每项：b（顶边/徽章色：闭集 ink/green/gold/ox）/ k（徽章词）/ n（要点，可用 `<em>` 标绿、`<span class="ox">` 标暖橙）/ d（说明） |
| concl | 是 | 结论条（沉底通栏，可用 `<b>` 标金） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- cards 必须为 3 项（校验闸拦截）。
- b 语义：gold=常规重点，green=方法/实例，ox=提醒/易错/警告，ink=中性。

## 模板对应

程序/页面生成.py `t_cards3`；PPTX 声明式映射见 程序/pptx映射.py `映射表["cards3"]`
