# 页型卡-section_duo

- id: 页型卡-section_duo
- 卡型: 页型卡
- 标题: 章节页（撞色块式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 章节

## 适用场景

章节过渡页。大面积撞色色块分割页面，编号标题压于色块上。创意/品牌/设计类提案、年轻化课程。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `03 / 18`） |
| kick | 是 | 章节 kicker（如 `CHAPTER 01`，大写+宽字距） |
| title | 是 | 章节标题（中文 ≤12 字，最多两行） |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| num | 否 | 大编号（如 `01`；缺省取 kick 末段） |
| sub | 否 | 一句话副标题（≤30 字） |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 色块占比 30–60%，用品牌主色 + 辅助色
- 文字对比度 ≥4.5:1；标题反白
- 金融/国企/政府类正式汇报禁用
- 章节页信息密度铁律：只允许编号+标题+可选一句副标题；bullet、正文、图表一律禁止

程序/页面生成.py `t_section_duo`
