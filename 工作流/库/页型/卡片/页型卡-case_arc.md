# 页型卡-case_arc

- id: 页型卡-case_arc
- 卡型: 页型卡
- 标题: 转变弧
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案
- 版式族: 图文

## 适用场景

客户故事的转变叙事：横向弧线/阶梯呈现"旧世界→转折点→方法→新世界→下一步"，
转折点高亮，强调转变过程的戏剧性。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `case_arc`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（断言句，≤30 中文字） |
| stages | 是 | 数组，4–5 项；每项：k（阶段名，必填）/ d（说明，必填） |
| img | 否 | 配图 |
| cap | 否 | 图片说明 |
| mask | 否 | 图片遮罩 |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- Turning Point 不可缺：不许 Before 直跳 After，转变弧必须有转折点阶段。
- 配色走主题令牌，不许在字段里写色值。

## 模板对应

程序/页面生成.py `t_case_arc`；PPTX 声明式映射见 程序/pptx映射.py `映射表["case_arc"]`
