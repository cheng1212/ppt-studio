# 页型卡-timeline

- id: 页型卡-timeline
- 卡型: 页型卡
- 标题: 时间线页（横向轴线 + 上下交错里程碑卡）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿

## 适用场景

讲"历程/沿革"类知识页：一条横向时间轴，3–6 个里程碑节点上下交错排布，
每个节点 = 时间标签（金）+ 标题 + 一句话说明。轴线与节点圆点走 svg.py 图元。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `timeline`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| nodes | 是 | 数组 3–6 项；每项：t（时间标签）/ h（标题）/ d（说明，≤40 字） |
| concl | 是 | 金边结论条（可用 `<b>` 标绿） |
| foot | 是 | 底部右注 |

## 纪律

- 节点 3–6 个，超了拆页；d 说明一句话，不许展开成段落
- 时间标签必须可排序、有真实依据，不许编年份
- 知识页禁止裸列表：结论条是标配，须答得出「去掉它损失什么信息」

## 模板对应

程序/页面生成.py `t_timeline`（轴线走 程序/svg.py `timeline_axis`）
