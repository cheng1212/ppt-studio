# 页型卡-problem_pain

- id: 页型卡-problem_pain
- 卡型: 页型卡
- 标题: 痛点图标阵列
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 草案（2026-10-06）
- 版式族: 观点

## 适用场景

问题/痛点页：3–4 个痛点横向阵列，每张 icon 占位＋痛点论断加粗＋q 量化小字。
适合"为什么要做这件事"的开场问题页、现状诊断页。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `problem_pain`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用反问或断言） |
| pains | 是 | 数组，3–4 项；每项：k（痛点论断，必填）/ q（量化补充，必填） |
| foot | 是 | 底部右注 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 痛点必须定量：每项 k 必须配 q 量化补充（校验闸拦截：q 缺失/无数字即 FAIL）。
- pains 必须为 3–4 项（校验闸拦截）。
- 须与后页方案对应：每个痛点在后续方案页必须有回应项，不许提出无解的问题。
- 配色走主题令牌，不许在字段里写色值。

程序/页面生成.py `t_problem_pain`；PPTX 声明式映射见 程序/pptx映射.py `映射表["problem_pain"]`
