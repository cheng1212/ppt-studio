# 页型卡-stepper

- id: 页型卡-stepper
- 卡型: 页型卡
- 标题: 横向步骤条（流程横向 2–4 步 + 提示框沉底）
- 来源轨: 库内装配
- 生产者: Muse
- 状态: 定稿（2026-10-05）

## 适用场景

流程关系（方法步骤链、判断链）：横向 2–4 步，编号圆 + 标题 + 说明，步骤间金色箭头，提示框沉底。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `stepper`（闭集） |
| brow/no/kick | 是 | 页眉左/页眉右页码/金色 kick 眉题 |
| title | 是 | 标题（可用 `<span class="q">` 标绿半句） |
| steps | 是 | 数组，2–4 项；每项：t（步骤标题）/ d（说明） |
| warn | 是 | 提示框（沉底通栏，可用 `<b>` 标金） |
| foot | 是 | 底部右注 |

## 纪律

- steps 必须为 2–4 项（校验闸拦截）。
