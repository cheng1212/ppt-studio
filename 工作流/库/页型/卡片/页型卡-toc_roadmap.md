# 页型卡-toc_roadmap

- id: 页型卡-toc_roadmap
- 卡型: 页型卡
- 标题: 目录（路线图/进度式）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 草案
- 版式族: 目录

## 适用场景

目录/议程页。顶部进度条 + 横向节点：已讲章节置灰/打勾、当前章节高亮。长会议/培训中反复回到此页指示进度。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `{tpl}`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| current | 是 | 当前章节序号（1 起，1 ≤ current ≤ items 数） |
| items | 是 | 数组，3–6 项；每项：no（编号）/ zh（章节标题） |
| items[].desc | 否 | 一句话描述 |
| bg | 否 | 背景纹理：dots/grid/diagonal/mesh/glow（闭集） |

## 纪律

- 一次性静态目录禁用此页型（进度元素无意义）
- 已讲章节置灰或缩小，当前章节主题色高亮 + 指示条
- 进度指示必须与实际演讲进度一致

## 模板对应

程序/页面生成.py `t_toc_roadmap`
