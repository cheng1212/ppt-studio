# 页型卡-section

- id: 页型卡-section
- 卡型: 页型卡
- 标题: 章节页（深底 ghost 编号）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿

## 适用场景

章节分隔页。深底 + 右上 ghost 大编号 + 设问式副标题。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `section`（闭集） |
| brow | 是 | 页眉左 |
| no | 是 | 页眉右（页码） |
| ghost | 是 | ghost 大编号（如 `01`） |
| eb | 是 | 英文眉题 |
| title | 是 | 章标题（118px） |
| sub | 是 | 字符串数组，设问/引子（<br> 连接） |
| foot | 是 | 底部注脚 |

## 纪律

- sub 用设问句式，不用陈述句（引发好奇）
- ghost 编号与章节序号一致

## 模板对应

程序/页面生成.py `t_section`
