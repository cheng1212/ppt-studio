# 页型卡-cover_anchor

- id: 页型卡-cover_anchor
- 卡型: 页型卡
- 标题: 封面（单锚点）
- 来源轨: 封面版式深调研 encoding（2026-10-06，16 版式分类）
- 生产者: chengge
- 状态: 草案
- 版式族: 封面

## 适用场景

章节封面、年报式封面（巨型年份/数字）、Keynote 章节过渡。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id（如 C3-大字报），HTML 文件名来源 |
| tpl | 是 | 固定值（闭集） |
| num | 是 | 巨型锚点（年份/数字/关键词） |
| eyebrow | 是 | 顶部英文眉题（全大写宽字距） |
| title | 是 | 中文大标题 |
| sub | 是 | 一句话副标题 |
| foot | 是 | 左下注脚 |
| corner | 否 | 右下角标注（通用字段，各主题自定） |

## 纪律

- 锚点字号≥2×标题（HTML 用 em 相对单位，不写硬编码 px）
- 锚点须与主题强关联；为放而放禁用
- 主封面信息不全（缺副标题/署名）时打回
