# 页型卡-toc_grid

- id: 页型卡-toc_grid
- 卡型: 页型卡
- 标题: 目录（2×2 带图卡）
- 来源轨: 库内装配
- 生产者: chengge
- 状态: 定稿

## 适用场景

目录/学习导航页。2×2 卡片，每卡 = 图 + 编号 + 中文名 + 描述。

## 数据字段表（字段/必填/说明）

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 页 id |
| tpl | 是 | 固定 `toc_grid`（闭集） |
| brow | 是 | 页眉左（英文章名） |
| no | 是 | 页眉右（页码，如 `02 / 18`） |
| title | 是 | 中文大标题 |
| sub | 是 | 副标题 |
| en | 是 | 金色英文行 |
| foot | 是 | 底部左注 |
| cards | 是 | 数组，4 项；每项：no（编号/英文）/ zh（中文名）/ desc（描述）/ img（素材文件名） |
| cards[].contain | 否 | true 时图 contain 显示（实物特写防裁切） |

## 纪律

- cards 固定 4 项（2×2 网格）；多于 4 须另起页型
- 实物特写图 contain 完整显示；场景图 cover

## 模板对应

程序/页面生成.py `t_toc_grid`
