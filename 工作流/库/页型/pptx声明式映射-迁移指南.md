# PPTX 声明式映射 · 迁移指南

## 为什么

`pptx导出.py` 里每个页型都要手写一个 `r_*` 函数。新页型（chart/kpi_hero/cover_split…）
长期没有导出器——加页型的人不会顺手写导出，写导出的人要读懂 HTML 版式。

## 解法

页面 = 组件列表（数据，不是代码）。`程序/pptx映射.py` 里给新页型写一份映射声明，
通用渲染器负责执行。坐标从 HTML 模板的版式数值抄。

## 组件闭集

| 组件 | 用途 |
|------|------|
| 底色 | 全页底色 `{"组件":"底色","fill":"bg"}` |
| 文本 | `{"组件":"文本","字段":"title","x":..,"y":..,"w":..,"h":..,"size":45,"color":"ink","bold":True,"align":"left"}` |
| 图片 | `{"组件":"图片","字段":"img",...,"fit":"cover\|contain"}`（data URI/路径都行） |
| 矩形 | 卡片底 `{"组件":"矩形",...,"fill":"card"}` |
| 线条 | `{"组件":"线条","x1":..,"y1":..,"x2":..,"y2":..,"color":"gold","w":2}` |
| 徽章 | `{"组件":"徽章","字段":"k",...,"kind":"gold"}` |
| 页眉/页脚 | 复用 `page_head` / `page_foot`（含 brow/no/kick/title） |
| 结论条 | `{"组件":"结论条","字段":"concl","x":..,"y":..,"w":..}` |
| 循环 | 对数组字段重复渲染：`{"组件":"循环","字段":"kpis","模板":[...]}`，组内用 `{it.v}` 取项字段、`{i}` 取序号（1起）、`{96+592*i}` 做算术偏移、`{it}` 取项本身 |

字段解析规则：`{模板}` 走模板变量；裸字段名先查当前项(it)再查页面(p)，查不到当字面量。

## 迁移步骤（以 chart 为例）

1. 打开 HTML 模板，抄版式数值（x/y/w/h）。
2. 在 `映射表` 加一项：`"chart": [ ...组件列表... ]`。
3. 跑 `pptx导出.py` + LibreOffice 转 PDF 目检。
4. 页眉已渲染 brow/no/kick/title，映射里不要重复写标题。

## 优先级

- 声明式优先：`pptx导出.py` 主循环先查 `映射表`，没有才用手写 `RENDER`。
- 新页型一律走声明式，不再写 `r_*`。
- 老 7 个手写页型按需迁移，不强制。
