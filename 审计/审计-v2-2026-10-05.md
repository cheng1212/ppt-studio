## 审计意见

### A1（建议修）：规约要求主题卡必填"间距"，主题问卷生成的骨架没有"间距"节

- 实证：`工作流/规约/卡型规约.json`（单行文件）`卡型.主题卡.必填` 含 `"间距"`；
  `工作流/程序/主题问卷.py:103-124` 骨架节列表为：一句话 / 问卷答案 / 配色令牌表 / 字体与字号 / 页眉页脚系统 / 结构件清单 / 设计纪律 / css路径 / 下游——无"间距"节。
- 修法二选一：① 骨架加 `## 间距` 节（待填）；② 规约必填去掉"间距"。修完保证"卡型规约.正文模板"与生成器骨架节一一对应。

### A2（建议修）：页型卡"页型id"口径 + 卡文件本身零校验是已知缺口

- 实证 1：`规约/卡型规约.json` `卡型.页型卡.必填` 要求 `"页型id"`，但 5 张页型卡（`库/页型/卡片/页型卡-*.md`）都没有独立的"页型id"字段，只有 `id: 页型卡-<tpl>`。修法：规约注明"页型id 即 id 去掉 `页型卡-` 前缀"，或卡补字段。
- 实证 2：`工作流/程序/校验.py:1-114` 只校验 pages.json（①–⑤）与主题卡存在+CSS 令牌（⑥）；页型卡、素材卡文件本身不在校验范围内。规约里"兜底"节（未登记卡型提示）与定案 D2（"页型卡数据字段节必须与模板实际读取字段一致，漂移即修卡"）目前全靠人工，无机检。
- 修法：短期在 `工作流/README.md` 设计纪律里明确"页型卡漂移靠人工对账（S2 式抽查），暂无机检"；长期可给校验器加 `--卡` 模式按规约校验卡文件。本次审计的人工抽查（S2）结论是：当前 5 张页型卡无漂移。

### A3（顺手修）：`P5-原子结构.png` 是孤儿文件

- 实证：`工作流/示例-化学钠/化学-钠及其化合物/页/` 下有 `P5-原子结构.png`（256KB），但无 `P5-原子结构.html`，且 `页/pages.json` 只有 5 条（P1/P2/P3/P4/P6），无 P5 条目。疑似 v1 残留。
- 修法：确认无用后删除；若有用则补数据条目+重新生成。

### A4（顺手修）：`esc()` 不转义与数据手写 `&amp;` 相悖

- 实证：`工作流/程序/页面生成.py` 的 `esc()` 注释"内容自信，不做转义"；但 `页/pages.json` P1 条目 `eyebrow` 写的是 `"Sodium &amp; Its Compounds"`——写数据的人必须懂 HTML 实体，与"只写字段不写样式"的初衷相悖。
- 修法二选一：① 页型卡数据字段表注明"特殊字符用 HTML 实体"；② `esc()` 改为 `html.escape` + 白名单放行页型卡允许的标签（`<span class="q">`、`<b>`、`<em>`）。

### A5（顺手修）：未使用的 import（lint 级）

- 实证：`工作流/程序/页面生成.py:17` 引入的 `OK/USAGE/ERR/WORKFLOW` 在文件内无引用（仅 import 行出现）；
  `工作流/程序/截图.py:9` 引入的 `OK/FAIL/ERR` 无引用（仅 `USAGE` 被 `sys.exit(USAGE)` 使用）。
- 修法：删掉未用名。`截图.py` 的 `print("OK", …)` 是字符串字面量，与 `基座.OK` 无关，不要误删后误改打印。

### A6（顺手修）：`千问生图.py` docstring 文件名过时

- 实证：`工作流/程序/生图/千问生图.py:2` docstring 仍写 `用法: python qwen_gen.py …`，文件已改名。
- 修法：改为 `python 千问生图.py --prompt "…" --out out.png`。

### A7（仅说明）：力学试跑 P3 图文不符是诚实占位，可接受

- 实证：`示例-验证/力学试跑/页/pages.json` P3（惯性页）`img` 用 `na-cut.png`（切割金属钠），`cap` 却写"小车在不同表面滑行距离对比"；但 `库/素材/素材卡.jsonl` 第 14 行（一句话）已声明"用于力学试跑惯性页左图（验证项目，非真实产品图）"，属诚实占位。
- 建议：`示例-验证/` 下加一句 README 说明该目录图片为占位、非真实产品图，避免后人误用。当前状态可接受，不 blocking。
