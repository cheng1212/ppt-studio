# ppt-studio · PPT 工作流

数据驱动的课件生产流水线：**Library（知识卡库）定规约，Python 程序负责执行**。
核心理念只有一句：**能固定的都固定，不让大模型瞎发挥**——
主题只回答固定的 6 个问题，页面数据只许出现规约里定义的字段，生成前必须过校验闸。

`工作流/示例-化学钠/` 是用这套工具产出的第一套完整课件：
高中化学《钠及其化合物》（SODIUM · 活性之源主题）。

## 它是怎么工作的

```
定主题：主题问卷.py（6 问闭集收敛）→ 主题卡 → theme-<主题>.css
做页面：生图 → 写 pages.json → 校验.py（闸）→ 页面生成.py → 截图.py
```

- **库/**：知识卡——主题卡（设计决策）、页型卡（18 种布局的数据字段与纪律）、
  素材台账、`_步.json`（每一步的机器可读定义）
- **规约/**：JSON schema——卡型规约（卡长什么样）、主题问卷规约（问哪 6 个问题）。
  改 schema 即改程序行为，不改代码
- **程序/**：执行层——`基座.py` 共享底座，`校验.py` 是数据闸，
  `页面生成.py` 数据→HTML，`截图.py` HTML→PNG，`图表.py` 数据→matplotlib 图表
  （bar/line/pie，Tufte/Few/Knaflic 风格焊死），`配色.py` 对比度+色盲安全调色板

## 仓库结构

```
工作流/
  程序/    基座.py / 校验.py / 主题问卷.py / 页面生成.py / 截图.py / 图表.py / 配色.py / 生图/
  库/      主题/ / 页型/ / 素材/ / theme-sodium.css / theme-ocean.css
  规约/    卡型规约.json / 主题问卷规约.json
  示例-化学钠/   产品：《钠及其化合物》课件
  示例-验证/     验证：ocean 主题 3 页试跑（证明换主题不碰程序）
```

## 快速开始

```bash
pip install -r 工作流/requirements.txt
python -m playwright install chromium   # 截图用

# 新增一页：写数据 → 过闸 → 生成 → 出图
python 工作流/程序/校验.py
python 工作流/程序/页面生成.py
python 工作流/程序/截图.py "工作流/示例-化学钠/化学-钠及其化合物/页"

# 新主题：问卷 → 填卡 → 写 CSS → 过令牌闸
python 工作流/程序/主题问卷.py --主题 <名> --答案 answers.json
python 工作流/程序/校验.py --主题 <名>
```

环境变量：`PPT_PROJECT`（项目目录，相对 `工作流/`）、
`PPT_THEME_CSS`（主题 CSS，相对 `工作流/库/`，默认 `theme-sodium.css`）。

## 快速理解

- 审工作流 → 看 `工作流/README.md`
- 审规约 → 看 `工作流/规约/卡型规约.json`
- 审卡库 → 看 `工作流/库/主题/卡片/主题卡-sodium.md` + `工作流/库/页型/卡片/`
- 审产出效果 → 看 `工作流/示例-化学钠/化学-钠及其化合物/页/*.png`
  （与 `pages.json` 对照 = 数据如何变成页面）
